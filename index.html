Building

Right-drag orbit the camera, wheel zoom, W A S D / arrows pan, F focus the selected part, Delete removes it.
Select / Move / Scale edit one part (parts that belong to a model move, delete and duplicate together). Insert Part adds a brick, Duplicate copies the selection.

Running

Press Go to spawn Parrot Cay (the song plays), Stop to go back to building.
W / S forward / back, A / D turn, arrow keys work too, and U H J K if you turn that on in MENU. Pose lets you position and rotate the limbs.
The Timer counts up from 0 while you run and resets when you stop. Score does nothing yet; it is there for models that need it.

Right panel

? this window. RESET GAME respawns the character. The magnifiers zoom in (+) and out (−).
The small figures: sit, stand up (you can only walk while standing) and climb the nearest ladder, which carries you up to the platform beside it.

Menu bar

File: New Baseplate, Save / Load a map as .json (you can leave the baseplate out when saving; loading a map without one keeps your current baseplate).
Insert: opens the Toolbox. It lists the built-in Ladder and every .json in Assets/Models.

Making models

A model is a .json file like a saved map, so the easiest way is to build it here and use File > Save Map. By hand:
{ "name": "My model",
  "parts": [
    { "x":0, "y":0.5, "z":0, "sx":4, "sy":1, "sz":2, "color":"#c4281c" },
    { "x":0, "y":6, "z":0, "sx":1, "sy":12, "sz":1, "color":"#da8541", "role":"ladder" },
    { "x":0, "y":11.5, "z":-2.5, "sx":4, "sy":1, "sz":4, "color":"#a3a2a5", "role":"platform" }
  ] }
x y z is the centre of a part, sx sy sz its size. Parts with "role":"ladder" can be climbed; the part with "role":"platform" is where you end up (you climb from the side opposite the platform).
Browsers can only read the Models folder when the page is served, e.g. run py -m http.server 8000 in this folder and open http://localhost:8000. Opened by double-click, use Load model .json... in the Toolbox instead.
